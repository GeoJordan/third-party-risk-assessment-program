## Inherent Risk Scoring Logic

## Scoring Criteria

| Factor                 | Score 1    | Score 3         | Score 5          |
| ---------------------- | ---------- | --------------- | ---------------- |
| Data Sensitivity       | Public     | Internal/PII    | PHI/PCI          |
| Access Level           | None       | Standard User   | Privileged/Admin |
| Business Criticality   | Low        | Medium          | Mission Critical |
| Regulatory Exposure    | None       | Moderate        | High             |
| Hosting Responsibility | No Hosting | Partial Hosting | Full Hosting     |

## Tier Thresholds

| Total Score | Tier     |
| ----------- | -------- |
| 5–9         | Low      |
| 10–14       | Medium   |
| 15–19       | High     |
| 20–25       | Critical |
